1. Тип "double" хранит числа в двоичном виде и не может точно преедать некоторые десятичные дроби (пример 0.1). Из-за этого копится погрешность,что недопустимо для денег. "decimal" работает точнее
2. Произойдет переполнение: число "завернется" по кругу и начнет считать с начала(пример, 255 + 1 = 0)
3. В Python тип может меняться, а "var" — это просто способ не писать тип вручную. Компилятор определяет тип один раз при создании переменной и потом его нельзя поменять
4. Всегда возвращает "string" 
5. "int.Parse" при ошибке «роняет» программу с ошибкой. "int.TryParse" не падает, а возвращает "false" и записывает 0.
6. "false" значит, что преобразовать не удалось. В переменную через "out" при этом попадет "0"
7. "TryParse" нужен при вводе данных от пользователя. Так как мы не знаем,что он введет, "TryParse", безопаснее - программа не упадет, если он ошибется
